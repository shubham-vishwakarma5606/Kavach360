# GitHub Pages 404 Hotfix

Copy these files to the ROOT of your GitHub repository:

- index.html
- app.html
- phishing-redirect.html
- .nojekyll

Also make sure the folder `final-release/` exists at the ROOT and contains:

- public-website.html
- final-portal.html
- phishing-redirect-page.html

GitHub Pages settings:

- Source: Deploy from a branch
- Branch: main
- Folder: /root
