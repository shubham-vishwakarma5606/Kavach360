# GitHub Pages Entry Points

This ZIP includes fixed GitHub Pages entry files at the repository root:

- `index.html` → redirects to `final-release/public-website.html`
- `app.html` → redirects to `final-release/final-portal.html`
- `phishing-redirect.html` → redirects to `final-release/phishing-redirect-page.html`

After uploading/pushing to GitHub Pages, open:

- Public website: `https://YOUR_USERNAME.github.io/Kavach360/`
- Portal demo: `https://YOUR_USERNAME.github.io/Kavach360/app.html`
- Phishing redirect demo: `https://YOUR_USERNAME.github.io/Kavach360/phishing-redirect.html`

GitHub Pages setting:

- Source: Deploy from branch
- Branch: `main`
- Folder: `/root`
