# Kavach360 Admin and User Guide

## 1. User Guide

### Login

Users log into the portal and use the left navigation.

### Dashboard

Shows:

- Assigned training
- Completion
- Cyber score
- Activity summary

### Training

Users can:

- View assigned modules
- Watch protected videos
- Complete quizzes
- Complete puzzles
- Download certificates after completion, if enabled

### Reporting Suspicious Activity

Users should report suspicious emails, SMS, WhatsApp messages, QR codes or links through the approved internal reporting method.

### Certificates

Certificates are issued based on training completion and score.

---

## 2. Customer Admin Guide

### Dashboard

Customer admins can view:

- Training completion
- Phishing click rate
- Report rate
- Department risk
- Compliance status

### Training Management

Admins can:

- Assign modules
- Upload custom content
- Track completion
- Review quiz scores

### Phishing Campaigns

Admins can:

- Create campaign
- Select scenario
- Schedule date/time
- Add consent note
- Complete approval checklist
- Select approved domain
- Assign users
- Launch safe campaign
- Review campaign report

### Users

Admins can:

- Add users
- Bulk upload users
- Assign departments
- Assign roles
- Track high-risk users

### Reports

Admins can view:

- Department risk
- User-wise report
- Completion report
- Phishing report
- Compliance mapping

### Settings

Admins can configure:

- Theme
- Company logo
- System emails
- User sync
- SSO
- Logs
- Reminders
- SMTP
- Security

---

## 3. Super Admin Guide

Super Admins manage:

- Customers
- Licences
- Trials
- Trial extension
- Master content
- Global reports
- Support
- Contribution moderation

---

## 4. Safety Rules

Phishing simulations must:

- Be approved
- Use approved domains
- Never collect real passwords
- Never deliver malware
- Use training landing pages
- Avoid public shaming
- Provide learning and reporting

---

## 5. Content Protection Rules

Production must enforce:

- Private file storage
- Signed URLs
- Access checks
- Watermarking
- Audit logs
- Licence checks
- Tenant isolation
