# Functional MVP Notes

## File

`portal-clean/functional-mvp.html`

## What is functional now

This is a browser-based functional prototype using localStorage as a demo database.

Functional features:

- Add users
- Delete users
- Add training modules
- Assign modules to users
- Add phishing templates
- Schedule phishing campaigns
- Assign campaign users
- Save SMTP/settings
- View dashboards
- View individual user report
- View campaign results
- Export demo database as JSON
- Reset demo database

## Important

This is not a production backend. It proves the UI and workflow. Production should use PostgreSQL, backend APIs, RBAC, private storage and signed URLs.
