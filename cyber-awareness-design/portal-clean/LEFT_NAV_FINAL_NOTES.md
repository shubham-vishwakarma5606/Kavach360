# Left Navigation Final Update

The portal has been updated so navigation and utility actions are on the left side.

## Changes

- Removed visible top navigation bar.
- Main feature navigation remains in the left sidebar.
- Theme toggle moved to left sidebar.
- Support Centre moved to left sidebar.
- User profile moved to left sidebar.
- Settings internal navigation remains left-side subnavigation.
- Page-level Save/Reset buttons remain only where functionally required, such as Settings.

## Final UI Rule

All navigation should be left aligned. Top area is reserved for page title and page-specific actions only.
