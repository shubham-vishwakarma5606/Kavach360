# Single Portal Clean UI Notes

## User request addressed

- Dashboard, Training, Settings and all features are in one portal.
- Features are controlled from the left navigation, not top navigation.
- Settings matches the reference style but uses a left-side settings subnavigation instead of top tabs.
- Public website and portal can use different colour directions.
- Clean UI with minimal buttons.
- Animations are subtle and professional: hover lift, active states, theme selection feedback and toast notifications.

## Main file

`portal-clean/single-portal.html`

## Final recommendation

Use:

- `index.html` for public animated marketing website.
- `portal-clean/single-portal.html` for the logged-in app portal.

This keeps the marketing site visually impressive and the portal clean/professional.
