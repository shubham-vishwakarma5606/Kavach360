# Optimized Portal Flow Notes

## Goal

The user requested a cleaner, less confusing design and a flow similar to the GoldPhish-style reference.

## What changed

- Created `optimized-flow.html`.
- Reduced unnecessary buttons.
- Kept one clear sidebar flow:
  - Dashboard
  - Training
  - Phishing
  - Users
  - Company
  - Licences
  - Reports
  - Policies
  - Settings
- Training page follows the reference flow:
  - Page title: Training
  - Tabs: My Training, Campaigns, Content
  - Card grid for modules
- Removed excessive action buttons from the main content area.
- Support actions are moved into the Support Centre drawer.
- Cards are clickable and view-only.
- Content protection message is retained.

## Final UI Strategy

- Public marketing site can remain animated/premium.
- Logged-in portal should use this clean optimized layout.
- Avoid too many CTAs inside portal pages.
- Use sidebar and tabs as the main navigation.
- Use one primary action per functional page.
